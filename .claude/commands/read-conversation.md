# 過去の対話履歴を読み込む

`meta/history/CONVERSATION_HISTORY.md` に記録された過去の対話履歴を読み込み、要約して表示する。

---

## 実行手順

1. `meta/history/CONVERSATION_HISTORY.md` を読み込む
2. 記録されているセッションの一覧を表示
3. 各セッションの概要を簡潔に要約（重要度ランク順）
4. 重要な学びや設計原則を抽出

### アーカイブを読む条件

以下の場合は `meta/history/archive/CONVERSATION_HISTORY_YYYYMMDD.md` も読み込む：

- ユーザーが明示的に要求した場合
- 現在の履歴に関連する過去の経緯を確認する必要がある場合
- 特定のトピックの全履歴を追跡する必要がある場合

---

## 出力フォーマット

```
対話履歴サマリー

## 記録されているセッション
1. YYYY-MM-DD: タイトル [★★★★★]
2. YYYY-MM-DD: タイトル [★★★★☆]
...

## 主要な成果
- 成果1
- 成果2

## 重要な設計原則
1. 原則1
2. 原則2
```

---

## 活用シーン

| シーン | 目的 |
|--------|------|
| プロジェクト開始時 | 過去の判断理由を理解 |
| 新メンバー参加時 | プロジェクトの進化の経緯を共有 |
| 類似問題発生時 | 過去の解決策を参照 |
| 振り返り時 | 学びを再確認 |

---

## 注意事項

- ファイルが存在しない場合は、その旨を通知
- 500行を超える場合は、最新のセッションを重点的に要約
- アーカイブを読む場合は、読み込んだファイル名を明示
